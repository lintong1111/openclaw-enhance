# OpenClaw Workspace 配置包

包含所有 OpenClaw Workspace 的配置文件。

## 文件列表

| 文件 | 说明 |
|------|------|
| `SOUL.md` | 贾维斯灵魂配置 |
| `USER.md` | 用户画像 |
| `AGENTS.md` | 多智能体调度 |
| `HEARTBEAT.md` | 后台任务监控 |
| `MEMORY.md` | 长期记忆 |
| `TOOLS.md` | 工具配置 |
| `IDENTITY.md` | 身份配置 |
| `.learnings/` | 学习记录 |
| `.agent-prompts/` | Agent 提示词 |
| `hooks/` | Hook 配置 |

## 安装

安装脚本会自动复制这些文件到 `~/.openclaw/workspace/`
